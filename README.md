# Anderson's Smoking Que

Smoked Low. Served Bold.

This repository contains the Vite + React + TypeScript + Supabase project scaffold for the customer website, admin dashboard, Supabase SQL/functions, CI workflows, and Playwright smoke/admin tests.

## Required environment variables

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`
- `SITE_URL`
- `ADMIN_TEST_EMAIL`
- `ADMIN_TEST_PASSWORD`
